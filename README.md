# SubHub

Консоль для продажи подписок: сама создаёт аккаунты Flipkart, покупает
YouTube Premium (Flipkart Black) и выдаёт ссылку покупателю на GGSELL.
Всё управляется из одного окна — или из Telegram.

> Репозиторий: [github.com/crownfall90-dot/SubHub](https://github.com/crownfall90-dot/SubHub)

---

## Что умеет

| | |
|---|---|
| **Аккаунты** | Покупает номер +91 (GrizzlySMS / PVAPins), принимает OTP, входит на Flipkart, сохраняет профиль Chrome |
| **Покупка** | Адрес → чекаут → оплата картой или подарочными картами → ссылка активации |
| **Подбор профиля** | Кнопка «Купить» сама берёт подходящий аккаунт: сначала с заполненными данными, потом любой свободный |
| **Брак** | `Currently out of stock` — дефект аккаунта: профиль удаляется сам, покупка идёт на следующем |
| **GGSELL** | Заказы, переписка с покупателем, автовыдача ссылки, баланс продавца |
| **Telegram** | Полное управление с телефона: запуск, профили, покупка, гифт-карты, логи, обновление |
| **Экономия** | Кэш Chrome чистится после каждого закрытия — профиль весит ~8 МБ вместо ~90 |

Номера возвращаются автоматически: если код не пришёл — отмена и возврат денег;
если код пришёл — вход доводится до конца, чтобы оплаченный номер не пропал.

## Быстрый старт

**Нужно:** Windows 10/11, [Python 3.10+](https://www.python.org/downloads/)
(при установке отметить **Add Python to PATH**), [Google Chrome](https://www.google.com/chrome/).

```bash
git clone https://github.com/crownfall90-dot/SubHub.git
cd SubHub
```

Скопировать шаблоны и заполнить ключи:

```
config.yaml.example  →  config.yaml
secrets.yaml.example →  secrets.yaml
```

| Ключ | Где | Зачем |
|------|-----|-------|
| GrizzlySMS | `secrets.yaml` → `grizzlysms.api_key` | Номера +91 |
| PVAPins | `secrets.yaml` → `pvapins.api_key` | Запасной провайдер номеров |
| Telegram | `secrets.yaml` → `telegram.token` | Бот ([@BotFather](https://t.me/BotFather)) |
| GGSELL | `secrets.yaml` → `ggsel.api_key`, `seller_id` | Маркетплейс (опционально) |
| Карта оплаты | в консоли → пункт `0` | Оплата на Flipkart |

Запуск — двойной клик по **`menu.bat`** (или `python -m subhub`). Telegram-бот и
фоновые мониторы стартуют вместе с консолью. Зависимости и Chromium ставятся
сами при первом запуске.

**VPN.** Flipkart недоступен из части стран — держите свой VPN включённым на ПК.
Браузер ходит напрямую через системное соединение.

## Меню

**Автоматизация** — `1` вход на ПК · `2` подбор аккаунта в TG · `8` вход с данными ·
`9` полный цикл · `Б` **купить** (сам подберёт профиль)

**Профили** — `3` открыть в Chrome · `П` проверить активацию выданных ·
`К` восстановить из куков · `6` архив · `Ч` очистить кэш

**GGSELL** — `7` панель продавца: баланс, заказы, переписка

**Настройки** — `М` SMS-провайдер · `0` карты · `Г` подарочные карты ·
`4` логи · `С` остановить всё · `У` обновление

---

## Обновления

Главное меню → **`У`**. Консоль скачивает файлы с ветки `master` и перезапускается.

Загрузка идёт по одному соединению, с повторами, и **применяется только если
скачалось всё** — оборванное обновление не оставит установку наполовину обновлённой.
Список файлов — `subhub/menu.py` → `_UPDATE_FILES`; проверить доступность:

```bash
python scripts/check_ota_reachable.py
```

Для разработки: `git pull origin master` + `pip install -r requirements.txt`.

## Проверки

```bash
for %f in (scripts\test_*.py) do python %f
```

Быстрые, без сети и без денег. Отдельно `scripts/check_*.py` — живые проверки
(ходят в интернет), запускаются вручную.

## Безопасность

`config.yaml`, `secrets.yaml`, `data/cards.json`, `chrome_profiles*/`,
`cookies_backup/` — уже в `.gitignore`. Дополнительно поставьте хук, который
не даст закоммитить секреты даже через `git add -f`:

```bash
python scripts/install_hooks.py
```

## Если что-то не так

**Flipkart не открывается** — включите VPN на ПК, проверьте, что установлен Chrome.

**Профиль «не залогинен»** — сессия отозвана на стороне Flipkart; восстановление из
куков поможет, только если бэкап свежий. Иначе нужен новый вход по OTP.

**Две копии бота** — оставьте одно окно консоли: бота держит один экземпляр.
